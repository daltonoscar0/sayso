# Decisions

One line each: what was decided, what else was on the table, why.

## Engine

- **C++17, zero runtime dependencies, flat layout, `g++` one-liners plus a Makefile** — alt: CMake, a header-only design; matches Scalpel's build story and morphology's Makefile, which is the same author's pattern for a project that consumes Scalpel.
- **Tropical semiring (min, +) with `float` arc and final weights** — alt: log semiring, integer costs; tropical gives best-path decoding directly, which is the only decoding Sayso needs.
- **One process-wide `SymbolTable`** — alt: per-FST tables with relabelling on composition; every grammar composes with every other, so a shared table removes an entire class of bug for the cost of a singleton.
- **Written side is one symbol per character, spoken side one symbol per word** — alt: characters throughout, words throughout; digits have no word boundaries and number words have no useful character structure, so each side gets the granularity it actually has.
- **Mohri's three-state epsilon filter in `compose`** — alt: remove epsilons first; the filter is ~15 lines and keeps grammars readable, since insertions (`ε:dollars`) and deletions (`$:ε`) are how currency and date grammars express themselves.
- **Dijkstra for shortest path, weights asserted non-negative** — alt: Bellman-Ford, generic shortest-distance over the semiring; every cost in Sayso is a penalty, so negative weights would be a bug rather than a feature.
- **Hand-rolled property harness (`property.h`, xorshift64\* + shrinking)** — alt: a test framework as a dev dependency; a seeded generator plus a shrinker is ~80 lines, and keeping it in-tree means the test build has the same zero-dependency story as the library.

## Grammars

- **ITN is `invert()` of the verbalisation grammar, never a second grammar** — alt: hand-written inverse rules; a second grammar drifts, and inversion makes the weighting scheme govern both directions by construction.
- **Hyphenation is a separate word-level FST composed onto every number** — alt: enumerating "twenty-five" as an atom in the cardinal table; a 9x8 table becomes one machine with 8 states, and inverting it is what lets ITN read both "twenty five" and "twenty-five".
- **Ordinals are `suffix_stripper ∘ cardinal ∘ ordinaliser`** — alt: a parallel ordinal number table; composition expresses the actual generalisation (only the last word of a numeral inflects) and makes suffix agreement (21st, not 21th) fall out of inversion instead of a lookup.
- **Digit-by-digit fallback priced per digit (0.5), not as a flat entry cost** — alt: a flat penalty; per-digit keeps the fallback under the per-character cost of leaving a long token alone while never outbidding a real reading of a short one.
- **Thousands commas are optional on the written side at a cost** — alt: a separate comma-stripping pass; one weighted arc makes TTS accept "1,234" and makes ITN emit "1234" from the same machine.
- **`minus` is generated for a leading `-`, `negative` merely accepted** — alt: accepting only one; the weight records the preference without narrowing what ITN can read.
- **Cardinals reach 999,999,999,999 (twelve digits)** — alt: stopping at the required nine digits; the scale loop is the same code either way, so billions came free.

## Money and dates

- **Grammars are lazily-composed `Cascade`s, not eagerly composed machines** — alt: composing every stage at build time; the date grammar's formats composed against its canonical machine came to 1.2M states, of which any one input visits a few hundred, so stages are composed against the input lattice instead.
- **Priority union is expressed as a hair of weight, not as set difference** — alt: implementing `difference` and subtracting the specific case from the general one; a 0.01 margin on the general branch makes the specific one win wherever both apply, in both directions, for one line of code.
- **`hyphenated()` reads its vocabulary off the machine it is given** — alt: a hand-maintained word list; a missing identity arc does not pass a word through, it kills the path, and that bug cost real debugging time before the vocabulary became derived.
- **One canonical date grammar (M/D/YYYY) plus character-level format normalisers** — alt: one machine per written format; reordering a field costs one path per value of that field, and holding the day (31) or year (200) in a small rewrite machine is far cheaper than holding it across a copy of the day and year verbalisers.
- **ISO dates are limited to years 1900-2099** — alt: all four-digit years; each year is a distinct path through the reorder machine, and 200 covers every realistic date at a tenth the size.
- **Dates require all three fields** — alt: making the year optional; "March 14" is common, but an optional year makes "may second" a date and the classifier has no context to tell that from the verb, so the ambiguity is refused rather than guessed at. The cost is real and is paid elsewhere: "June 2015" is not a date either, which is why the year reading had to become available to a bare cardinal (below).
- **A bare four-digit number in 1100-2099 is read as a year** — alt: licensing the year reading only inside a date, which is what Sayso did until the real Google TN slice was scored; that one difference was 147 of 300 TTS mismatches, and fixing it took the corpus number from 40.0% to 62.8%. Expressed as priority union by margin — a hair on the general cardinal branch — so both wordings still read back to the same digits. The cost, pinned by a test, is that a four-digit *quantity* in that range is read as a year too.
- **The year reading is licensed for a bare span only** — alt: putting it in `cardinal_core_fst()`; MONEY, MEASURE, DECIMAL and FRACTION embed that machine, and a number inside a larger semiotic object is a quantity, so "$1984" and "1984 m" must stay cardinals. Adding the branch in `cardinal_grammar()` rather than in the shared core is what draws that line, and it draws it structurally rather than by weight.
- **`year_reading()` lives in numbers.cpp, not dates.cpp** — alt: a second copy for the cardinal grammar; two statements of how English says a year would drift, and the date field is now the same machine with a wider century range and the cardinal fallback switched on.
- **Sayso speaks a date month-first whatever order it was written in** — alt: Kestrel's order-preserving reading, where "28 February 2016" is "the twenty-eighth of february twenty sixteen"; that is 134 of the 186 remaining corpus mismatches and would be the single largest further gain, but it means giving up "every written format reaches the same spoken form", which is pinned by a test and a round-trip property and is what lets ITN canonicalise at all. Declined deliberately; the README says so with the number attached.
- **The dollar is the canonical currency; others pay a hair** — alt: leaving the tie; "ninety-nine cents" fits dollars and euros equally, and an arbitrary tie-break is a coin flip that changes between builds.
- **Format penalties are small (0.5-0.7), not large** — alt: the 2.0-3.0 they started at; they only have to beat the canonical format's zero, and a large penalty made a date span look expensive to the classifier, which then read "2015-03-14" as three cardinals separated by minus signs.
- **Homographs always convert in ITN ("I second the motion" -> "I 2nd the motion")** — alt: a stop-word list; the classifier models no context, so this is exactly the job deferred to the neural reranker, and the behaviour is pinned by a test rather than left to be discovered.

## Decimals, fractions, times and measures

- **A decimal's tail is read digit by digit, at no cost** — alt: reusing the cardinal grammar's per-digit fallback; that path is priced as a last resort because for an integer it is one, and after a point it is the only correct reading, so it has to be free.
- **The decimal grammar carries no magnitude words** — alt: a " million" branch like the currency grammar's; "3.5 million" already comes out right with DECIMAL taking "3.5" and PLAIN copying "million" through in both directions, so the branch would only add states to say what falls out anyway.
- **A missing leading zero costs differently on each tape** — alt: one penalty for both; "0.5" said as "point five" and ".5" written for "0.5" are different elisions, and giving the spoken one the lower cost is what makes ITN write "0.5" rather than ".5" while still reading both.
- **Fraction denominators are a table that stops at single-word ordinals** — alt: deriving them from the ordinal grammar; 2 and 4 are suppletive ("half", "quarter") so a derivation needs exceptions anyway, and a compound plural like "twenty-fifths" is one the hyphenator cannot rebuild — it joins a tens word to a unit *ordinal*, and "fifths" is not one. 32 and 64 are listed with both spellings outright for that reason.
- **The mixed-number article is the standalone weight, reversed** — alt: two weights; "1/2" alone is "one half" and "2 1/2" is "two and a half", which is one preference that points opposite ways in the two branches, so it is one number applied to whichever branch needs it.
- **"over" forms are not read** — alt: accepting "three over four"; it is real speech, but it doubles the denominator machine to say what the ordinary form already says, and nothing writes it.
- **A time's minute field is exactly two digits** — alt: accepting one; it is the only thing standing between the grammar and every ratio and score in English, and "3:5" is not a time anyone writes.
- **Whether a round hour is spoken depends on the meridiem** — alt: one reading; "3:00" is "three o'clock" but "3:00 pm" is "three p m", so the grammar has two cores that differ only in which way one weight leans.
- **The meridiem is spoken "p m", two words** — alt: "pm" as one; that is the Google TN convention and what a recogniser emits, and the written side canonicalises to "pm" regardless.
- **Times carry no seconds field** — alt: reading "3:30:15"; there is no settled spoken convention for it to canonicalise *to*, and guessing one would be inventing a target rather than normalising to it.
- **Units whose written form is an ordinary English word are left out** — alt: a complete SI table; CLASSIFY models no context, so "in", "s", "h", "t" and "a" would read "3 in the morning" as three inches. This is the one place where the right answer was to make the grammar smaller.
- **The unit table is stored in the case units are spelled with** — alt: an all-lowercase table; CLASSIFY folds a span's case before any grammar sees it, so the folded spelling is the only one TTS can match and the canonical one the only one ITN will write, and a hair of weight is what makes the second true. This is the exception to the case-folding decision recorded under Pipeline.
- **"pounds" is money, "lb" is weight** — alt: leaving the tie; both classes fit the same span and the classifier has no context, so the measure reading is priced to lose the spoken form and keep the written one, which no currency writes.
- **Measures accept cardinals and decimals but not fractions** — alt: "1/2 cup"; the units that take a fraction are cooking measures, none of which are in the table, so it would be a machine three times the size in service of spans that cannot occur.

## The classes the corpus asked for

- **`Grammar::speaking_only`, for classes that must not be read backwards** — alt: a weight large enough to lose in ITN; there is none. CLASSIFY prices PLAIN per character, so a five-letter word costs 5.0 against an entry cost of 0.05, and a class whose written side is ordinary English always outbids leaving the word alone in *both* directions. The flag records that a class is one-directional; it is not a second grammar, and every other class is still inverted.
- **Roman numerals go inside `cardinal_grammar()` rather than into a class of their own** — alt: a `ROMAN` class; inside CARDINAL a weight suffices, because ITN's spoken "two" meets "2" at a hair and "II" at a real penalty and the digits win. A separate class would have had to beat PLAIN instead, and could not — the same argument that forces `speaking_only` on the others, run the other way.
- **Roman numerals are a table, not a parser** — alt: `M{0,4}(CM|CD|D?C{0,3})...`; that accepts "MIX", "DID" and "CIVIC", and spans arrive case-folded so there is no capital left to tell a numeral from a word. Single letters are excluded outright: I, V, X, L, C, D and M are 5.7% numerals in the shard, and "I" alone is most of the remainder.
- **Roman numerals read as cardinals, not ordinals** — alt: the regnal reading; "Henry VIII" is "the eighth" and "World War II" is "two", the only difference is the preceding word, and the reference splits 4,349 cardinal against 1,453 ordinal. Three in four is the bet.
- **`VERBATIM` is declined entirely** — alt: implementing its symbol table; "&" → "and" is 40% of the class and inverted rewrites 189,026 ordinary "and" tokens into ampersands, its Greek table is 91.5% a tokeniser artefact (whole Greek words shredded into letters, against which the inverse would rewrite 593 English words into Greek), and the remainder is a letter-spellout belonging to LETTERS. Nothing durable survived the attack.
- **`LETTERS` reads dotted shapes only** — alt: bare all-caps runs, which are the largest shape in the data; spans are case-folded before a grammar sees them, so nothing can tell "PDF" from "pdf" and a bare-run branch would spell out every lower-case word it met. The dots are the only signal that survives folding.
- **`LETTERS` needs two letters** — alt: one; Scalpel attaches a trailing full stop to short tokens, so "the 1980s." arrives as [1980] [s] [.] and a one-letter rule reads the last two as an initial — spelling out the decade's plural and eating the sentence's full stop, since a claimed span is replaced whole. It costs the bare initial of "J. Smith".
- **`ABBREV` includes only expansions at least twenty times commoner than the ordinary word** — alt: the full 89-type list; "no" expands to "number" 288 times and is the word "no" 8,805 times, and CLASSIFY sees no context. "co", "min" and "col" go the same way. "st" is kept at 3,205 saint against 156 street, which is a bet, not a certainty.
- **Dialect conversion is out of scope** — alt: matching the reference; Kestrel turns "colour" into "color" and "metres" into "meters" across 12,380 tokens, and that is not text normalisation. It costs about 1% of the corpus score and the README counts it separately.
- **`RANGE` is hyphen-only** — alt: including the colon, which looks like the same construction; 95.7% of colon "to" readings in the shard are bibliographic citations ("Astrophysical Journal 94: 501"), which nobody speaks that way, and admitting them would put RANGE against TIME on every clock. The en dash never occurs and every one of the 11,063 em dashes is silent.
- **`RANGE` refuses the year-month shape structurally, not by weight** — alt: relying on the entry cost; a range's shape is the prefix of an ISO date, and cost alone worked only while zero-padding happened to make the alternative expensive — "2015-03-14" was safe and "2011-11-11" was not. The grammar now refuses a four-digit operand followed by a month-shaped one outright.
- **`RANGE`'s entry cost is derived, and bounded on both sides** — alt: picking a number; it must exceed 0.14 to lose to DATE and stay under 0.42 to beat CARDINAL("1") plus CARDINAL("-10") on the unspaced "1-10". Both bounds were found by getting them wrong first.
- **`RANGE` takes an 84% bet, and the honest figure is nearer 70%** — alt: not having the class; the 84% is measured only over hyphens Kestrel had already split into their own token, and Sayso's tokeniser also splits the ISBNs and phone numbers Kestrel kept whole. Recorded because the README should not quote the flattering number.
- **`DECADE` is its own class, not part of DATE** — alt: folding it in; the date grammar is a machine for three reordered fields and a decade has none of that structure. It shares the year reading with `numbers.cpp` rather than restating it.
- **The `DECADE` short form starts at twenty** — alt: including "10s"; "tens" is an ordinary English quantifier and this grammar runs backwards, so a "10s" branch turns "tens of thousands of casualties" into "10s of thousands". "hundreds" and "thousands" are safe because they only appear after a century word.
- **The adapter splits a trailing full stop off a token unless the token already contains one** — alt: leaving Scalpel's tokenisation alone; it attaches the stop to short tokens as an abbreviation guess, so "1980s." and "5 km." were unclaimable and whatever did claim them swallowed the sentence's punctuation. Every class was silently failing at the end of a sentence. "U.S." and "p.m." keep their dots because they contain more than one.
- **Money writes a magnitude word only where digits cannot say the same thing** — alt: leaving the tie; "fifty thousand dollars" fits "$50 thousand" and "$50000" equally and a test was pinning the coin flip. "$2.5 million" survives because no numeral spells those words.
- **A time's full-stop separator is licensed only before a meridiem** — alt: always; "10.30" on its own is a decimal far more often than it is a time, and the classifier has no context.
- **A round hour is "o'clock" below thirteen and "hundred" above it** — alt: one reading; "10:00" is ten o'clock and "18:00" is eighteen hundred, so the hour field is split and one weight leans each way.

## Composing grammars without copying them

- **Concatenation is distributed over unions, not the other way round** — alt: one branch per surface form, each beginning with the amount; `A·B ∪ A·C` and `A·(B ∪ C)` accept the same strings with the same weights, but the first holds two copies of `A`. With `A` the cardinal machine and `B`, `C`... thirty-odd measure units or seven currency tails, that is the whole cost of the grammar. Applied to money, measures, fractions and decimals, it made the eight-class classifier faster than the four-class one it replaced.
- **An optional sign is concatenated once, not distributed over the branches** — alt: `unsigned ∪ minus·unsigned ∪ negative·unsigned`; the same identity, worth three copies of whatever follows it.
- **`reweight` may be moved inside a concatenation** — alt: leaving it wrapping the whole branch; it prepends a single epsilon arc, and the tropical semiring sums along a path, so the total is the same wherever on the path the cost sits. That is what lets a penalised branch share its prefix with an unpenalised one.
- **The span cache holds every class's answers under one key** — alt: one entry per (class, span); the span text is the expensive part of the key, and building it once per span start rather than once per class is most of what the warm path costs once the grammars are all cache hits.

## Pipeline

- **Scalpel is the tokeniser; Sayso adds an offset-repair adapter, not a fork** — alt: patching Scalpel, reimplementing tokenisation; Scalpel's `START` state ignores HYPHEN/APOSTROPHE/OTHER characters, so `-` in `2015-03-14` and `€` in `€40` are dropped, and comparing token offsets against the input recovers them generically.
- **CLASSIFY is a lattice WFST over token boundaries, decoded by the same `shortest_path`** — alt: a longest-match scan; making it a lattice means longest-match is an emergent consequence of pricing PLAIN per character rather than a separate rule.
- **CLASSIFY runs each grammar once per span *start*, not once per span** — alt: one composition per span; the shared prefixes of a start's spans were being re-walked, and composing against an all-final input chain to read every input position at once (`Cascade::apply_prefixes`) took the cold path from 61 to 221 sentences a second and the warm path from 3,900 to 61,600.
- **Span length is capped, and the cap differs by direction (8 written, 24 spoken)** — alt: one unbounded cap; the longest written span is "$1,234,567.89" at eight tokens while an unhyphenated spoken amount runs to twenty-four, and with prefix composition the cap costs nothing it does not use.
- **The spoken cap went 12 → 16 → 24 as the classifier got cheaper** — alt: leaving it at 12; relaxed scoring showed 12 splitting "eight hundred forty six million ..." into three numbers, and speech recognisers do not hyphenate, so 12 was wrong for the direction that consumes ASR output. At 16 it cost fourfold throughput; after prefix composition, 24 costs nothing.
- **`Cascade` holds its stages by reference** — alt: by value; stages are large and always function-local statics, but passing a temporary compiles and then dangles, so the header says so and a test was bitten by it once.
- **Span verbalisations are memoised per (direction, class, text)** — alt: recomputing; the classifier asks the same question of the same span text constantly across a corpus, and the cache is what gets the throughput number into the thousands of sentences per second.
- **Spans are case-folded before reaching a grammar** — alt: case variants inside every grammar; the spoken side is lowercase by construction, and the only canonical written forms that contain a letter needing case are the measure units, which carry both spellings in their own table rather than making every grammar case-aware.
- **Serialisation copies the gaps between segments verbatim from the input** — alt: a detokeniser; byte offsets make the untouched text exactly untouched, so quoting, spacing and stray punctuation cannot be damaged by normalisation.
- **FIRST- and LAST-set prefilters on every cascade** — alt: composing and letting it fail; the classifier asks every grammar about every span, and the overwhelming majority of those questions are settled by the first and last symbols alone — no currency grammar has anything to say about a span starting with a digit, and no number grammar about one ending in "summary".
- **Composed states are packed into a 64-bit key in an `unordered_map`** — alt: `std::map<std::tuple<int,int,int>>`; composition is the library's hot loop and the tuple comparison was showing up as a constant factor on every call.

## Evaluation

- **The eval harness is C++ and zero-dependency; only the NeMo comparison is Python** — alt: a Python harness for both; the Sayso half then could not be run without the dev environment, which defeats the point of having one.
- **An optional fourth "canonical written" column in the slice** — alt: scoring ITN against the corpus's written column; inverse normalisation is only defined up to a canonical form, and scoring against an arbitrary one put DATE at 24% where every "error" was a correctly normalised date in a different format.
- **The synthetic slice is generated by an independent reference verbaliser, not by the grammars** — alt: generating it from the FSTs; that scores 100% by construction and measures nothing, and the README says plainly what the synthetic numbers do and do not mean.
- **Two throughput numbers, cold and warm** — alt: quoting the warm one; they differ by an order of magnitude and quoting only the flattering one would be misleading.
- **Two scoring modes, strict and relaxed** — alt: strict only; strict penalises another system for writing "thirty fourth" or "nine hundred and forty two", which are not errors, so a cross-system number under strict scoring measures conformance to this slice's conventions rather than quality.
- **The relaxed mode de-hyphenates the ITN input** — alt: feeding both systems hyphenated text; inverse normalisers consume ASR output, which has no hyphens, so hyphenated input tests something no deployment ever sees — and de-hyphenating exposed a genuine Sayso bug in the span cap.
- **Relaxed scoring drops standalone punctuation from both sides** — alt: comparing it; the Google TN reference marks punctuation "sil", written but not spoken, so its spoken column has none, while Sayso copies punctuation through verbatim because a TTS front end must. Without this the real slice scored 0.0% on every class, every sentence failing on a comma — which measured a difference of format and nothing else.
- **`--errors=N`** — alt: the fixed ten; ten mismatches are enough to notice a pattern and useless for counting one, and every real conclusion in the README's corpus section came from categorising all of them.
- **The NeMo comparison is reported with its caveats in the table, not below it** — alt: quoting 100% against 18%; the slice's reference conventions are Sayso's own, NeMo scores 100% on ORDINAL where the conventions coincide, and most remaining gaps are differences of target rather than errors.
